## 2. 转成施工验收

- 空会话反复启动/结束不新增事实，不把旧记忆重写为新经历或延长 TTL。
- 同文内容在不同桌宠分区内互不覆盖、互不可见；源码中缺隔离不能推断真实部署已越权。
- 新旧事实更新可追溯；同 ID、同创建时间但不同 revision 的卡片/索引不能复用旧正文。
- 两份候选乱序返回，旧版本拒绝；同一操作重试幂等；取消、撤权和删宠后提交失败。
- 归档失败不删除源条目；写盘、索引失败分别处理，不把不可检索当作已销毁。
- 删除处理派生摘要、卡片、索引和在途任务；备份/外部副本边界单独报告。
- 模型记忆提议不直接授予工具权限，不允许通过错误、日志或来源链接读取别人私密原文。
