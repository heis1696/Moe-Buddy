## 1. 文章给出的启发与证据边界

文章将细粒度事实聚合为实体卡片，再构建关联网络。可借其组织方式，但不据厂商自报收益选择产品；本文未复跑基准。特别注意，文章表格的约三倍 token 成本列在 LightRAG 一侧，不应反向归给三层方案。产品状态另以现行官方文档为准，不以历史公测描述当作当前事实。

官方产品资料：`https://help.aliyun.com/zh/rds/apsaradb-rds-for-mysql/rds-contextdb-quick-start`。其记忆沉淀、程序性经验晋升、共享与用户隔离是产品自身的机制，不能只因名词类似就映射为我们的实体卡片或每桌宠隔离。

## 2. 保留的核心结论

| 内部表示 | 本项目的候选承载 | 权威性 |
| --- | --- | --- |
| 原子事实 | 有主体、适用条件、证据和版本的 MemoryRecord；情景记录与资料仍可保留必要上下文 | 已提交记录是权威数据，不凭字数或模型输出自动成为事实 |
| 实体卡片 | 对已获准、有效记录做读时聚合的视图 | 非权威；可重建，不能覆盖来源 |
| 关系图 | 未来有收益证据时引入的关系索引 | 非权威；每条边继承来源、推断性质与权限 |

上述是 private/shared 内部的表示与视图，不增加记忆大类。关系图是否值得做应由具体检索用例和实测决定，不与“是否多宠”机械绑定。

## 3. 领队纠正的实现判断

### 3.1 小文本条目不等于原子事实

`src/cognition/memory.ts:24` 的现有 MemoryEntry 是分段文本容器，短文本也可以有多个事实、代词、推断或摘要；没有结构化主体和谓词。不能据此认为只补 epistemic/supersedes 两字段就完成建模。

新框架还需要稳定归属、revision、有效状态、来源版本、派生关系、使用规则、候选与回执。可选字段只解决局部读兼容，不等于旧档零迁移；解析器与存储往返也必须验证字段是否保留。旧 source 不自动证明原始发言者与事实性质。

### 3.2 旧过滤器不是多角色权限门

`src/cognition/memory.ts:286` 目前按过期、secret 与 trust 过滤，并未按活动宠身份验证归属。新卡片必须先经过新服务的分区、用途、传输与状态过滤，不能直接复用旧 alive 集合就宣称跨宠隔离。

### 3.3 hits 目前没有半衰期

`src/cognition/memory.ts:220` 是 hits + 新近度衰减 + 关键词加成；衰减的是新近度，不是 hits。性质、来源可信、使用统计和检索排序仍应分开；是否改变计分另做比较，不编造现有行为。

### 3.4 升库资格不等于发布许可

`src/cognition/memory.ts:329` 的 canPromoteToShared 仅检查 normal 与最低 trust；`src/cognition/memory.ts:334` 的 promoteToShared 是 scope 变换。它们没有完成身份、用户授权、来源有效性、风险或发布主体校验，不能当作 publishShared 的完整安全门。

### 3.5 派生缓存要依版本，不依创建时间

不能用 id + createdAt 当完整缓存键：同一条目被修正后创建时间可以不变。候选键至少覆盖分区、记录与来源版本、相关策略及聚合规则版本；读取时仍核对当前权限与有效状态。别名未消歧时不自动合并，只做词面相似也不能把同名桌宠当作同一个主体。

## 4. 建议的最小实现方式

1. 先完成新记录契约、稳定身份与版本化存储；保留旧读写适配，不在旧文本字段上伪装新框架已完成。
2. 对事实候选增加受控主体、谓词和值/条件表达；主语不明、事实与推断冲突时保留候选或原记录，不靠摘要 prompt 强行归一。
3. 在授权过滤后的集合上生成卡片；第一版只聚合受控实体，如当前用户、当前桌宠和共享工具标识，不自动做开放式实体消歧。
4. 卡片列出支持记录及冲突，不把摘要反写为新的独立事实。来源被纠正、删除、撤权或换版本，卡片失效后重建。
5. 保留卡片失败或预算不足时的条目级回退；关系图、向量服务与卡片持久化均不作为首版依赖。

## 5. 必须增加的验收

- A/B 的同名、同文私密条目不能混合聚合；共享视图只能使用已发布记录。
- 相同 ID 与 createdAt、不同 revision 的输入必须产生不同有效结果；撤权后旧缓存不得继续返回。
- 删除事实后卡片与其派生索引不能残留正文；旧后台任务不能重建已失效卡片。
- 空会话反复读取/摘要不能制造新事实、提高可信度或给条目续期。
- 冲突事实保留时间和条件，不把“今天不想喝”改成永久偏好。

## 6. 不直接采纳

不照搬单一 confidence 统管真伪与热度、不以“模糊化”代替删除、不自动对齐各宠私人画像，不以文章安装脚本启动外部服务。

不接入云记忆产品是当前范围与授权选择，不是宣称所有网络服务都违反主进程零第三方依赖。私密信息是否可送往某个云端仍按现行同意规则与后续明确策略处理，不新增数据去向。
