Moe Buddy 0.1.0 · Windows 测试版

启动
1. 完整解压 ZIP 到可写目录（例如桌面），不要直接在压缩包内运行。
2. 双击「Moe Buddy.exe」。无需 Rust、Node 或命令行。
3. 需要 Windows x64 和 Microsoft Edge WebView2 Runtime；本包不包含该系统运行时。

退出
点击主窗左侧栏底部「退出应用」，或使用托盘菜单的退出项。
有未保存聊天或管理编辑时，先确认保留还是丢弃；取消后继续使用。
窗口右上角 X 只关闭聊天/隐藏到后台，宠物窗仍可工作。

数据
moe-buddy.portable 标记使程序使用同目录 data 子目录，WebView 缓存也在其中。
请保留该标记。勿将 data 删除来解决启动错误；完整退出后可整体备份。
同一目录只运行一个实例。升级时先退出，再替换程序，保留 data。
本包没有预置聊天、API Key、发送许可或私人素材。
密钥和发送许可仅保留在本次运行中，重启需要重新设置。

可以测试
从左侧栏切换聊天、伙伴、外观与动作、记忆、模型设置和运行诊断六个页面。
聊天、会话切换与归档、伙伴创建与切换、模型配置、人设、私密记忆管理。
配置模型需填写完整兼容接口地址并明确允许发送；默认不会向模型服务发请求。
打开「外观与动作」，将素材包目录（或 manifest.json）拖入素材区，选择动作、播放、暂停或卸载。
当前素材选择不跨重启保存，重新启动后再次拖入。素材换皮不会改变伙伴身份。

这是工程测试版：真实模型服务、IME、多屏/混合 DPI、实际掉电等尚未完成专项验收。
BUILD-INFO.json 记录构建信息；ZIP 旁的 .sha256 文件用于核对下载完整性。
