# Moe Buddy desktop host

## 日用初版接线（短会话试用，持续日用未通过）

主界面采用纸白与苔绿配色：左侧窄导航切换聊天、记忆、模型与运行记录，右侧管理抽屉默认收起。聊天在剩余区域居中，底部完整输入卡包含编辑区、快捷键提示与发送按钮；点击“聊天”收起抽屉并回到输入框。初始客户区 1120×760、最小 880×640（96 DPI）。旧版尺寸与截图是历史验收记录。

记忆支持关键词搜索（最多 100 条匹配结果）、新增、选中编辑、版本校验保存和确认删除；编辑框可滚动查看全文。查询在写入后保留，新建/刷新清空查询；编辑失败保留输入，关闭窗口时未保存的记忆另行确认。删除只影响后续记忆检索，不抹除已经生成的聊天内容。

第二步已接可配置 OpenAI-compatible Chat Completions：输入完整端点（含 `/chat/completions`）、模型、API Key 和人设，勾选发送许可后应用。许可覆盖人设、获准私密记忆和当前会话；没有许可不调用模型。HTTPS 或数值回环 HTTP，禁重定向、代理和自动重试；60 秒总超时、10 秒连接超时、128 KiB 响应上限。工作线程只持有不可变输入，主窗口不等待网络；未知结果不重发，迟到结果复验撤权、来源、版本与取消状态。

数据保存在 `%LOCALAPPDATA%\MoeBuddy\daily`：`memory.v1` 复用 LocalMemory 权威日志，`chat/` 复用 RawLocalStore 原文格式，`settings.json` 仅含端点、模型和人设。API Key 与发送许可只在本次进程内，重启必须重新输入／确认。记忆持续保存，删除不代表日志物理擦除；聊天正常保留 30 天、回收 7 天，恢复不延长期限。恢复的历史只读展示，不恢复旧请求执行权，也不自动作为新会话模型输入。中断／未知历史保守阻止发送。坏档、占用和未完成提交保留现场，不以新空档覆盖。

第三步已通过可控回环服务执行完整原生窗口链：首次配置、业务发送、版本化编辑记忆及下轮召回、关闭重启、认证失败、真实超时、撤权拒绝迟到结果和未知不重发；也验证设置保存／读取失败。异步明确失败恢复原草稿，等待期间的新草稿不被覆盖；HTTP 成功但没有有效正文仍按未知隔离。尚无真实服务端点／凭据验收，详见 [审核记录](../../docs/REVIEW.md)。

**持续日用尚不通过**：未知／中断历史会持续禁发，目前没有保留旧记录另开会话的入口；外部回复按每轮 4096 字预留累计，65536 字应用预算下短输入约 15 轮即可达到上限，另有运行和原文硬容量，无自动轮转。不要删除存档或重发未知请求规避限制。恢复聊天只读、不自动接续模型上下文；新网络请求尚无完整诊断 run 事件。当前适合受控短会话验证，不承诺全天连续陪伴。

`apps/moe-buddy-desktop` 是 `moe-chat-app` 的 Windows 原生桌面呈现宿主（U2 首个可用版）。
它拥有事件循环、注入的单调时钟与全部窗口绘制；聊天、预设、记忆、日志与授权的业务规则
仍全部留在 `ChatApplication`，宿主只把窗口输入翻译为既有 `Action` 并渲染有界快照。
未配置模型时仍明确使用离线演示；浏览器验证宿主已随结构整理移除，桌面宿主是当前唯一产品入口。

## 运行（Windows）

```powershell
cargo run -p moe-buddy-desktop --locked --offline
```

非 Windows 目标以明确的平台消息退出；本 crate 不给核心或应用层增加 GUI 依赖。

## 界面与交互

- 布局：88px 左侧原生导航（图形和中文标签）、伙伴标题与真实模式标记、居中限宽聊天、
  128px 高输入卡，以及按需展开的 344px 右侧管理抽屉。底部以文字和图形显示状态、错误及撤销授权入口。
  纸白 `#F7F6F2` 画布、灰绿 `#ECEFE8` 导航、白面板、墨灰 `#262F2B` 正文、苔绿
  `#386653` 强调、辅助字 `#68736C`、边框 `#DCE2DA`。Microsoft YaHei UI 中文、系统等宽日志，
  8px 间距体系，18px 输入卡 / 10px 控件圆角；所有度量按 DPI 缩放。标识与导航图形由 GDI 绘制，无外部图片或字体请求。
- 聊天：Enter 发送、Shift+Enter 换行；输入法组合中（IMM 组合串非空）Enter 不会误发。
  发送失败保留草稿；结果未知时状态栏提示"请勿重发"并禁用发送；空草稿发送给出明确反馈。
  历史为自绘滚动气泡（滚轮/滚动条），用户标签右对齐；新消息及窗口高度变化时，原本贴底则继续跟随，用户上翻则保持阅读位置。
- 管理抽屉：记忆提供搜索、保存、新建/刷新、编辑选中与确认删除；空列表显示操作提示。
  模型入口保留离线预设切换及真实模型配置表单，人设、API Key 和发送许可独立明确。
  运行入口将事件与运行状态分两行展示，不含正文与凭据；诊断历史缺口由应用通知条呈现。
  导航沿用 `Action::Open/Hide`，再次点击当前管理入口或点击“聊天”收起抽屉，保留草稿。
- 窗口：初始客户区 1120×760（96 DPI 基准，随 DPI 缩放），最小客户区 880×640，
  支持缩放、最小化与关闭；标准标题栏，关闭/最小化操作明确；Tab 在输入框、按钮与列表间
  循环，焦点框可见。Per-Monitor v2 DPI 感知，字体与布局随窗口 DPI 重建。
- 生命周期语义：带未发送草稿时关闭先走 `ChatApplication` 的关闭确认，取消保留草稿，
  确认丢弃后才销毁窗口；"撤销授权"需确认，撤权后全部控件禁用并显示撤销通知。
  二进制为 GUI 子系统，启动失败以消息框呈现。

## 模块划分

| 文件 | 职责 |
| --- | --- |
| `src/main.rs` | 入口；非 Windows 明确退出。 |
| `src/theme.rs` | 纸白/苔绿颜色、字号与 8px 间距度量（纯数据，按 DPI 缩放）。 |
| `src/presenter.rs` | 快照到界面模型的纯映射：状态文案、严重度、可用性、边栏内容、Enter 策略。 |
| `src/chatlog.rs` | 聊天历史的纯布局计算与滚动钳制/贴底逻辑（测量器由宿主注入）。 |
| `src/layout.rs` | 导航、聊天、输入卡与管理面板的纯几何布局（含最小尺寸钳制）。 |
| `src/host/mod.rs` | 窗口/控件编排、IME 安全的 Enter 拦截、动作分发与关闭确认流程。 |
| `src/host/paint.rs` | 全部自绘：信息栏、通知条、聊天气泡、空态占位、状态条、自绘按钮与列表行。 |

`theme/presenter/chatlog/layout` 为纯 Rust；定向回归覆盖 Enter 策略、离线标记准确性、
结果未知禁用发送、96/120/144/192 DPI 布局与贴底滚动。原生宿主另验证导航/焦点/草稿、
空列表、模型表单、撤权与可重入生命周期；测试窗口使用合成应用，不设置生产测试后门。

## 边界

真实聊天出站和本地文件适配仅限上文日用接线；尚未进行真实模型服务验收，没有外部渠道、托盘或动画接入。诊断日志只经既有授权查询，记忆只经既有私密写入与授权检索。动画素材接入后仅接表现层，本宿主不因此接管业务规则。
